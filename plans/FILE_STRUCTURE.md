# Tutor File Structure

Starts from the current working directory.
```
tutor-memory # Folder comprising of tutor memory
|_ behaviour.md # Folder comprising of user desired tutor behaviour
{topic_name}
|_ assets
  |_ ... # Any provided assets for referencing within the document.
|_ agent.workpad.md # Use when thinking. 
|_ topic.md # Guide document file for each topic. Refer to GUIDE_DOCUMENT_TEMPLATE.md
```
