# Topic document guidance

Build the walkthrough with `topic_editContent`, following MANAGE_TOPIC.md. The app renders the document from the saved blocks.

Start with the example's goal, inputs, and setup visual. Follow the learner-answer workflow in MANAGE_TOPIC.md to extend the same example after checks and practice. Preserve the assets' required concepts and source examples as the story develops. Follow the scratchpad format: repeat 1–2 short explanation lines followed by a relevant rendered visual, with `---` between steps. Put each step's explanation, formulas and visual together in a `markdown` block; associate it with the curriculum using `sectionId`. Source images may follow in `source` blocks. Preserve stable block IDs when revising earlier working.

Add `source` blocks for citations or source images, and `term` blocks for taught terminology. Omit `present` when saving the walkthrough so chat keeps its own explanation; select blocks only on an explicit request to show saved content in chat. The app generates the title, directory, anchors, section headings and final terminology table.

Record checks and answers with the learning tools. Keep private assessment keys in the handoff.
