# Independent tests

Use the test workflow in [TUTOR_QUESTIONS_AND_DELIBERATE.md](TUTOR_QUESTIONS_AND_DELIBERATE.md#independent-tests). Retrieve mistakes and prior questions for the evaluated topics. Ask one question at a time, chosen dynamically from attached practice assets and then internet sources. Exclude walkthrough examples and questions already answered correctly. End when no suitable source remains; disclose unavailable web search. Combine covered concepts and target recorded mistakes where useful.

Persist the exact prompt and actual learner answer as structured question steps. Verify the key privately before asking. Evaluate reasoning with [WHAT_IS_UNDERSTANDING.md](WHAT_IS_UNDERSTANDING.md), deliberate disputed claims, and record confirmed mistakes with context and rationale. A solution exposed before an attempt is assisted practice, not independent mastery.
