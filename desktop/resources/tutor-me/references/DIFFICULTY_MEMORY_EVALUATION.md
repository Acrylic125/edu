# Evaluate mistake records

Check that each structured mistake's context preserves the actual disputed question/answer and that its issue states the confirmed error and rationale. Distinguish learner mistakes from tutor errors and unassessed reasoning. Preserve original answers across follow-ups. Verify that read-only retrieval never registers a writer and that unrelated topic summaries remain unchanged.

Use the part's objective and understoodWhen criteria to assess subsequent reasoning. Mistake records are historical evidence, not a separate mastery-status system. Mark a part completed only when all its goals are satisfied for the current thread. A finished walkthrough with unverified mastery is covered instead, using `complete` with `masteryVerified=false`.
